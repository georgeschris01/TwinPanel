# Contribuer à TwinPanel

**Français** · [English](#contributing-to-twinpanel)

TwinPanel est maintenu par son auteur. Vous pouvez y participer par les « Issues » (tickets) de ce dépôt.

## Demander une fonction

Ouvrez une Issue et décrivez ce que vous aimeriez faire et dans quelle situation. Il n'y a ni formulaire dans le programme ni envoi automatique.

## Signaler un problème

Ouvrez une Issue en indiquant :

- la version de TwinPanel (**À propos**) et celle de Windows ;
- ce que vous avez fait, ce que vous attendiez, ce qui s'est passé.

**N'écrivez jamais dans une Issue** de mot de passe, de phrase secrète, de clé privée, d'adresse de serveur ni de journal non relu : les Issues sont publiques.

Pour une faille de sécurité, n'ouvrez pas d'Issue : écrivez à admin@chrypox.be.

## Proposer une correction

Comme le prévoit l'article 6 de la licence :

1. Ouvrez une Issue et expliquez le problème constaté.
2. Dans sa description, partagez votre bout de code corrigé ou expliquez la modification à faire.
3. L'auteur analyse la proposition et, si elle est validée, l'intègre lui-même dans le code officiel.

En proposant une correction, vous acceptez qu'elle soit intégrée au projet sous la licence de TwinPanel. Vous serez crédité dans la liste des contributeurs.

Les demandes de fusion (« pull requests ») ne sont pas le moyen prévu : passez par une Issue.

## Copie du dépôt (« fork »)

GitHub permet à chacun de copier un dépôt public sur son propre compte. Cette copie ne donne aucun droit supplémentaire : la [licence](LICENSE) continue de s'appliquer. Vous pouvez modifier le code pour votre propre usage, mais pas diffuser une version modifiée ni réutiliser le code dans un autre projet.

# Contributing to TwinPanel

[Français](#contribuer-à-twinpanel) · **English**

TwinPanel is maintained by its author. You can take part through the Issues of this repository.

## Requesting a feature

Open an Issue and describe what you would like to do and in what situation. There is no form in the program and nothing is sent automatically.

## Reporting a problem

Open an Issue and state:

- the TwinPanel version (**About**) and the Windows version;
- what you did, what you expected, what happened.

**Never write in an Issue** a password, a passphrase, a private key, a server address or a log you have not reread: Issues are public.

For a security flaw, do not open an Issue: write to admin@chrypox.be.

## Proposing a fix

As set out in article 6 of the license:

1. Open an Issue and explain the problem.
2. In its description, share your corrected piece of code or explain the change to make.
3. The author reviews the proposal and, if it is accepted, adds it to the official code himself.

By proposing a fix, you agree that it may be included in the project under the TwinPanel license. You will be credited in the list of contributors.

Pull requests are not the intended way: please use an Issue.

## Copying the repository (fork)

GitHub lets anyone copy a public repository to their own account. This copy gives no additional rights: the [license](LICENSE) still applies, and the French text is the only one that prevails ([courtesy translation](LICENSE.en.txt)). You may modify the code for your own use, but you may not distribute a modified version or reuse the code in another project.
